# Strategy-factory capability matrix

Generated by `python -m edgelab.cli factory capabilities` from `edgelab/strategy/capabilities.py` (drift-tested). Each row names one status and the code that backs it.

Statuses: **executable** (implemented and numerically executed), **partial** (implemented with a stated limitation), **not_executable** (not executed by the engine; refused by name, never approximated), **data_unavailable** (the canonical Dukascopy data cannot support it).
